# D. C. R. S

Quiet pictures of ordinary days, by Sreenandan C. S, from Koorkenchery, Thrissur, Kerala.

This is a small photography portfolio with night streets, temple evenings, the sea at sunset and small things noticed along the way.

## Features

- Full-size photo view with zoom, previous and next
- Like and select photos (saved in your browser)
- Share button
- Comments on each photo (via GitHub Discussions)
